A database GUI that scales to huge tables

Browse, query and edit Postgres and SQLite, including the SQLite inside an app on your phone. Follow foreign keys like folders, see your schema as a graph, and ask for SQL in plain English.

Download for macOS Try in the browser Star on GitHub

macOS 12+ · Apple Silicon & Intel · MIT licensed

What it does

A desktop app first, built in Flutter. One canonical backend in the main window, with every other window talking to it, so long-running jobs don't care which windows are open.

Billion-row tables

Keyset pagination, never OFFSET, and a bounded in-memory window keep scrolling smooth however big the table gets.

Foreign keys as folders

A Finder-style column navigator: click a row, follow its foreign keys and inbound references, column by column.

Linked graph view

Pull rows onto a canvas and watch them connect. Expand any relation into a new node.

Schema diagrams

An auto-laid-out diagram of every table and relationship. Click a table to isolate its neighbourhood.

Plain English → SQL

Bring your own OpenAI, Anthropic or Gemini key. Generated SQL runs inside a read-only transaction by default.

Safe edits

Inline cell editing with optimistic concurrency: if someone changed the row underneath you, you get a conflict, not a silent overwrite.

Schema metadata & access control

Describe what columns mean, mask sensitive ones, define named queries, charts and dashboards, all from the database or a YAML file.

Shareable connections

Export a connection as an AES-256 encrypted .dbscopeconn file and open it on any machine.

Themes

VS Code Dark, Portal, and a faithful Windows 95. Themes are plugins, so you can write your own.

Connects to

Every backend is a plugin behind one interface, so adding MySQL, DuckDB or anything else is a self-contained package.

Postgres 14–17 Cloud SQL for Postgres (Auth Proxy started for you) Local SQLite files SQLite inside an Android / iOS app over USB Postgres from the browser via dbscope_pg_proxy

Vibe coded, in the open

Most of dbscope was written by an AI (Claude Code), with a human steering the architecture, reviewing and testing. It's used every day, but it will have rough edges. That's the invitation:

  1. Found a bug? Open an issue. Small ones count.
  2. Can fix it? Grab a good first issue and read CONTRIBUTING.md.
  3. Want a platform? Windows and Linux builds are waiting for someone.
